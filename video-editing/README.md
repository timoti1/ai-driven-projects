# Монтаж видео по транскрипту

Конвейер, который делает из длинной лекции с YouTube смонтированный выпуск:
вырезает паузы и оговорки, рисует справа панель-оглавление, которая сама
передвигается по мере лекции, добавляет заставку и титры, и **проверяет результат
числами** — потому что агент, который это собирает, не умеет смотреть на картинку.

Первый прогнанный выпуск: LearnToCode, «Теоретическая часть — 01. Процесс
обработки данных…» (`F6fCcoNNdEE`, 1:49:37 → 1:44:16, 413 склеек, −338 с, 22 темы
на панели). Разбор этого выпуска как worked example — в
[examples/EPISODE_01_worked_example.md](examples/EPISODE_01_worked_example.md).

Принцип, на котором всё держится: **сырьё → измеренные факты → план → рендер →
замеры готового файла**. Ни один шаг не угадывает содержимое; каждый читает
результат предыдущего. Новый выпуск = новый `edit/topics.json` и те же команды.

## Содержание папки

```
video-editing/
├── README.md        этот файл
├── Makefile         одна команда на шаг конвейера
├── requirements.txt python-зависимости
├── scripts/         конвейер (python + ffmpeg), все пути — относительно корня
├── docs/            конвейер, стиль, окружение, решения, ловушки, чек-лист
├── config/          style.example.json и topics.example.json — отправная точка
├── fonts/           Manrope (SIL OFL, лицензия рядом) — шрифт панели
└── examples/        разбор первого выпуска: что вырезано и почему
```

Рабочие файлы эпизода (`source/`, `work/`, `edit/`, `render/`, `logs/`) создаются
`make dirs` и в git не попадают — в репозитории только код и инструкции.

## Пререквизиты

| Что | Минимум | Зачем | Как проверить |
|---|---|---|---|
| Python | 3.10+ (проверено на 3.12) | скрипты | `python3 --version` |
| ffmpeg | 6.x, **с VAAPI** (AMD) или NVENC (NVIDIA) | вырезание, оверлеи, кодирование | `ffmpeg -hide_banner -encoders \| grep vaapi` |
| tesseract | 5.x + пакет `rus` | проверки читаемости текста | `tesseract --list-langs \| grep rus` |
| ffmpeg-фильтры | `overlay`, `drawtext`, `drawbox`, `trim/concat`, `select`, `fps` | панель и склейки | `ffmpeg -filters \| grep drawtext` |
| Python-пакеты | см. `requirements.txt` | анализ, пластина, лемматизация | `make deps` |
| GPU | опционально | кодирование: 6238 с 1080p25 за ~21 мин на VAAPI против ~50 мин на `libx264 -preset veryfast` | `make deps`, `scripts/gpu_free.py` |
| RAM | ~400 МБ RSS на рендер | граф сделан с плоской памятью | `scripts/gpu_free.py` печатает свободную RAM |
| Диск | ~10 ГБ на эпизод | исходник 1–2 ГБ + контент + финал | — |
| Шрифты | Manrope (уже лежит), DejaVu Sans Bold для галочки | панель и титры | `make deps` |
| Whisper | только если у источника нет субтитров | `scripts/transcribe.py`; веса модели ~3 ГБ в `~/.cache/huggingface` | — |

Ставится так:

```bash
sudo apt-get install ffmpeg tesseract-ocr tesseract-ocr-rus ttf-dejavu-core
```

Галочка `✓` (U+2713) есть в DejaVu, но не в Manrope — поэтому она рисуется
системным DejaVu Sans Bold. Если его нет, укажите в `edit/style.json`
`fonts.tick` любой шрифт с U+2713, иначе панель останется без отметок о
пройденных темах.

## Установка

```bash
git clone https://github.com/timoti1/ai-driven-projects
cd ai-driven-projects/video-editing
make venv        # .venv + requirements.txt
make deps        # проверка системы: ffmpeg+VAAPI, tesseract rus, python-пакеты
make dirs init   # source/ work/ edit/ render/ logs/ + edit/style.json, edit/topics.json
```

## Как смонтировать выпуск

Полный порядок с объяснением каждой команды — [docs/PIPELINE.md](docs/PIPELINE.md);
короткая версия для галочек — [docs/CHECKLIST.md](docs/CHECKLIST.md).

```bash
ID=<youtube id>

make download ID=$ID     # видео + русские субтитры + info.json
make analyze  ID=$ID     # транскрипт, тишина, громкость, движение экрана, слайды
#   ... руками правите edit/topics.json под этот выпуск (см. «Как называть темы»)
make plan                # план склеек + гейты видимости панели
make check               # audit_titles + probe_dashboard: оба обязаны быть PASS
make audio               # звуковая дорожка, нарезанная под те же склейки
make test                # короткий кусок 120 с, чтобы не рендерить вслепую
make render              # заставки + тело + склейка -> render/final.mp4
make verify              # замерить готовый файл против плана
```

Порядок `plan → check → audio → render` обязателен: `check` — это единственная
точка, где можно поймать нечитаемый текст и неверную геометрию до 20-минутного
рендера.

## Скрипты

| Скрипт | Читает | Пишет | Что проверяет / делает |
|---|---|---|---|
| `parse_vtt.py` | `.vtt` субтитры (в т. ч. авто) | `work/speech.json` | чистит «бегущее окно» автосубтитров, даёт слова с таймингами |
| `transcribe.py` | WAV | `work/speech.json` | то же через faster-whisper, если субтитров нет |
| `analyze_audio.py` | mp4 | `work/audio_stats.json`, тишина | где речь, где паузы, где громко |
| `detect_hum.py` | mp4 | `work/hum.json` | фоновый гул/фон (чтобы не резать по нему) |
| `analyze_motion.py` | mp4 | `work/motion.json` | движение экрана: слайд статичен или лектор скроллит |
| `extract_slides.py` | mp4 | `work/slides.json` | кадры-слайды |
| `gpu_free.py` | sysfs GPU, `/proc/meminfo` | — | на какой render-узел можно кодировать и есть ли запас RAM |
| `build_plan.py` | speech + silence + `edit/topics.json` | `edit/cuts.json`, `edit/topics_edited.json` | склейки по паузам, привязка тем к склейкам |
| `panel_gates.py` | `work/motion.json`, `work/thumbs` | `edit/panel_gates.json` | когда панель закрывает собой важное и должна прятаться |
| `make_plate.py` | `edit/style.json` | `render/panel_plate.png` | пластина панели (скругление, альфа, рамка) |
| `probe_dashboard.py` | style + темы | — | геометрия, альфа, контраст, OCR подписей. **PASS до рендера** |
| `audit_titles.py` | speech + `edit/topics.json` | — | каждая тема подтверждена словами её окна (через `anchor`) |
| `cut_audio.py` | `edit/cuts.json` | `render/audio_cut.wav` | звук ровно под видеорез |
| `render.py` | всё выше | `render/content.mp4`, `render/final.mp4` | ffmpeg-граф: рез, панель, заставки, титры |
| `verify_output.py` | `render/final.mp4` | `render/verified.json` | 8 разделов: кадры, длительности, панель, прогресс, склейки, титры |

## Как называть темы (правая панель — оглавление, а не пересказ)

Тема — это **концепция**, а не то, каким примером её показали. Правила, по
которым переделывалась панель первого выпуска:

- **Оглавление по предмету.** Строки идут так, как идёт тема лекции по
  дата-инжинирингу: структурированные → полуструктурированные →
  неструктурированные данные, форматы, Data Lake, затем этапы конвейера
  (извлечение, фильтрация, очистка, токенизация, скраппинг, агрегация), этапы,
  «структуры больше, данных меньше», хранение, инструменты.
- **Пример ≠ тема.** «Перегородки и доллары» — иллюстрация того, что делает ETL,
  поэтому строка называется «Аналогии, объясняющие ETL». Картинки и аудио —
  примеры неструктурированных данных, поэтому строка называет категорию, а не
  «картинки, аудио».
- **Термины отрасли — по-английски и без перевода:** `Data Lake`, `ETL`, `Spark`,
  `Power BI`. Не «Дейта Лейк», не «озеро данных», не транслитерация.
- **Обобщай, а не цитируй.** Строка — то, как бы её подписал лектор, а не дословные
  его слова.
- **У каждой строки обязателен `anchor`** — слово, которое лектор действительно
  произносит в этом окне. Абстрактное название без якоря — это догадка;
  `audit_titles.py` на такой строке падает.
- **`"recap": true`** на теме помечает строки, которые попадут в титры. Это флаг
  темы, а не список индексов: при удалении темы список индексов тихо сдвигается
  (именно так титры первого выпуска нарисовали 6 строк из 7 — см. GOTCHAS).
- **`vocabulary_ok`** в `topics.json` — список слов, которых нет в речи легально:
  `Data`, `Lake`, `ETL`, `Spark`, `BI`, `regex` и т. п.

## Стиль и панель

Всё оформление — палитра, геометрия, альфа пластины, шрифты, обводка, тексты
заставок, переходы, аудиотракт, параметры кодирования — в `edit/style.json`
(образец: `config/style.example.json`). Код переопределяет любой ключ без
правки, поэтому новый выпуск выглядит как предыдущий.

Строки панели живут в трёх состояниях, и это различимо числами:

| состояние | как выглядит | glyph/plate |
|---|---|---|
| ещё не дошли | тусклая, «еле видная» | ~1.5:1 |
| прошли | яркая + галочка `✓` | ~2.3:1 |
| идёт сейчас | белая, полужирная, точка-маркер | ~2.5:1 |

Часы — `H:MM:SS / H:MM:SS` (оба числа в одном формате; разделитель —
однопиксельная линия на измеренной позиции, чтобы не дрожала). Зелёной
подсветки строки и «таблеток» под строками нет: строки — обычный текст,
читаемость держит светлая полупрозрачная пластина и обводка 2 px.

Легимость проверяется, а не обещается: `probe_dashboard.py` считает контраст
строк, которые зритель читает (≥4:1 на их собственном фоне), и отдельно — что
будущие строки тусклее пройденных, но выше порога видимости
(`palette.min_upcoming_contrast`).

## Чего здесь нет

- Видео, аудио, кадров и миниатюр: `source/`, `work/`, `render/`, `logs/` — это
  рабочие папки, они в `.gitignore`.
- Весов модели Whisper (качаются при первом запуске `transcribe.py`).
- Файлов, которые конвейер производит сам: `edit/cuts.json`,
  `edit/topics_edited.json`, `edit/panel_gates.json`, `edit/stats.json`,
  `render/*.mp4`.
- Контейнера: конвейер рассчитан на Linux с системным ffmpeg. На другой ОС
  проверьте, что `drawtext` собирает кириллицу и что `silencedetect` печатает
  тайминги в том же виде.

## Известные ловушки

[docs/GOTCHAS.md](docs/GOTCHAS.md) — 32 разбора: что сломалось, как выглядело
симптом, и как это проверяется теперь. Перед первым рендером на новой машине
стоит прочитать ENVIRONMENT + GOTCHAS: почти каждая ошибка этого конвейера
была тихой (картинка без панели, тишина вместо звука, файл короче на 52 кадра).
